## Refactoring the Form

To support independent data uploads for images, we must decouple the `<input type="file">` logic from the primary `<form>` submission. If we relied entirely on synchronous HTML submissions, any error in uploading the image might wipe the user's typed description data on a page reload!

### Asynchronous Fetch Panels

On your `project-form.ejs`, you will construct a dedicated panel _just_ for screenshot management using JavaScript's native `Fetch` API mapping.

```html
{{/* Separated from the primary Project data form */}}
<div id="screenshot-manager">
  <h3>Screenshots</h3>

  <form id="upload-screenshot-form">
    <input type="file" name="screenshot" accept="image/*" required />
    <input type="text" name="altText" placeholder="Alt text..." />
    <input type="text" name="caption" placeholder="Image caption..." />
    <label>
      <input type="checkbox" name="isFeatured" /> Featured Thumbnail?
    </label>
    <button type="submit">Upload Document</button>
  </form>
</div>
```

<NoteBox title="Professor Solo">
  Notice that our `input[type="file"]` uses `accept="image/*"`. This natively
  signals to the browser's file picker to only display image files, working in
  tandem with the exact file filter we wrote into our multer middleware setup.
</NoteBox>

### Client-Side Binding

To catch the submission, block the page redirect, and fire the background request, write a client-side listener targeting the new form panel:

```javascript
document
  .getElementById("upload-screenshot-form")
  .addEventListener("submit", async (e) => {
    e.preventDefault();

    const formData = new FormData(e.target);

    try {
      // We send this payload to a specialized API endpoint!
      const res = await fetch(
        `/admin/projects/<%= project._id %>/screenshots`,
        {
          method: "POST",
          body: formData, // Note: no headers set; fetch auto-sets multipart/form-data for FormData payloads!
        },
      );

      if (res.ok) {
        location.reload(); // Quick refresh to show the new data loop
      }
    } catch (err) {
      console.error("Upload failed", err);
    }
  });
```
