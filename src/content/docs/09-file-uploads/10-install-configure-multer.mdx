## Installing Multer

The Express framework cannot natively digest file attachments on its own. We employ the middleware library **Multer** to parse `multipart/form-data`.

Run the installation script in your API's root directory:

```bash
npm install multer
```

Also, create the target `/public/uploads/` directory where Multer will automatically write your binary data to the disk structure.

## Writing the Middleware configuration

We want to intercept inbound file traffic explicitly, rename it based on safety protocols, test its type, and deposit it into our directory.

We will create a specific `middleware/upload.js` file:

```javascript
// middleware/upload.js
const path = require("path");
const multer = require("multer");

const storage = multer.diskStorage({
  // Deposit Location
  destination: (req, file, cb) => cb(null, "public/uploads"),

  // Safe Naming Protocol
  filename: (req, file, cb) => {
    const safeBase = path
      .basename(file.originalname, path.extname(file.originalname))
      .toLowerCase()
      .replace(/[^a-z0-9\-]+/g, "-") // Replaces spaces with dashes
      .replace(/-+/g, "-")
      .replace(/^-|-$/g, "");

    const unique = Date.now();

    // Assembled specific filename: your-image-1293849182.jpg
    cb(null, `${safeBase}-${unique}${path.extname(file.originalname)}`);
  },
});

function fileFilter(req, file, cb) {
  // Silent rejection of PDFs, texts, exes...
  if (!file.mimetype.startsWith("image/")) return cb(null, false);
  cb(null, true);
}

const upload = multer({ storage, fileFilter });

module.exports = upload;
```

<CautionBox title="T.A. Watts" type="warning">
  Why use regex to create our own `filename` execution instead of keeping
  whatever you uploaded? **Security.** If a user uploads a file titled
  `../../system-takeover.exe`, you must strip the executable type and sanitize
  the directory traversal commands from the name before parsing.
</CautionBox>
