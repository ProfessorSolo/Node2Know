## Pushing to Arrays

Inside our database handler, saving subdocuments is fundamentally just interacting with native JavaScript arrays! We run a standard `findById()`, get the parent Project Document, and then `push()` a new Object into its schema-restricted array.

```javascript
// data/projects.js

async addScreenshot(projectId, fileData, metaData) {
  try {
    const project = await Project.findById(projectId);
    if (!project) return { success: false, error: "Project not found" };

    // The subdocument shape matching screenshotSchema
    const newScreenshot = {
      originalName: fileData.originalname,
      filename: fileData.filename,     // The safe name multer generated
      mimeType: fileData.mimetype,
      size: fileData.size,
      altText: metaData.altText,
      caption: metaData.caption,
      isFeatured: metaData.isFeatured,
      order: project.screenshots.length // Stick this one at the very end of the line
    };

    project.screenshots.push(newScreenshot);
    await project.save(); // Commits the embedded array directly into Mongo

    return { success: true, project };
  } catch (error) {
    return { success: false, error };
  }
}
```

### The Featured Flag Check

<CautionBox title="T.A. Watts" type="warning">
  If the `isFeatured` flag is true in the `metadata` object... how do we ensure
  that *no other* screenshot in the array is also marked as featured? A Project
  cover image can only be one thing!
</CautionBox>

If you want to ensure singular featured coverage, you can add a mapping loop _before_ you push the new screenshot into the array.

```javascript
// Before pushing:
if (metaData.isFeatured === true) {
  // Map everyone else to false first!
  project.screenshots.forEach((s) => (s.isFeatured = false));
}
```
