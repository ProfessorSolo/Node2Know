### Challenge 3: The Solo Special (Hard)

**Scenario:** A user wants to search for projects by `slug`, but they might type it in UPPERCASE using SPACES (e.g., "MY COOL APP").
**Task:** Write a function that takes a messy input string, converts it to a proper slug (lowercase, hyphens), and _then_ searches the database for it.

<NoteBox title="AI Prompt" type="tip">
